# Atajos de teclado

Los atajos imitan a los de VS Code. En macOS y Linux, <kbd>Ctrl</kbd> equivale a <kbd>Cmd</kbd> donde corresponde.

## Ejecución

| Acción | Atajo |
| --- | --- |
| Ejecutar sentencia o selección | <kbd>Ctrl</kbd>+<kbd>Enter</kbd> |
| Ejecutar script | <kbd>Alt</kbd>+<kbd>X</kbd> o <kbd>F5</kbd> |
| Ejecutar en una pestaña de resultado nueva | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>Enter</kbd> |
| Cancelar | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Q</kbd> o <kbd>Alt</kbd>+<kbd>Pausa</kbd> |
| Explicar plan | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>E</kbd> |
| Explicar y ejecutar | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>Shift</kbd>+<kbd>E</kbd> |
| Commit / Rollback (modo manual) | <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>C</kbd> / <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>R</kbd> |
| Formatear SQL | <kbd>Shift</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> |

:::

## Personalizar los atajos

Los atajos se guardan en un `keybindings.json` en la carpeta de datos de la aplicación, con el **formato de VS Code**:

```json
[
  { "key": "ctrl+e", "command": "db.executeStatement", "when": "editorTextFocus" }
]
```

- `key`, `command` y `when` funcionan como en VS Code. Los contextos disponibles son `editorTextFocus`, `resultsFocus`, `gridFocus`, `treeFocus` e `isProduction`.
- Para **quitar** un atajo, antepón `-` al comando: `{ "key": "ctrl+enter", "command": "-db.executeStatement" }`.
- Todos los comandos tienen un identificador `db.*` estable, visible en la paleta de comandos. Las acciones propias de Monaco se pueden reasignar con su id (por ejemplo `editor.action.copyLinesDownAction`).
